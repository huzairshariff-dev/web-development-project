# Huzair Shariff - Portfolio (Internship Project)

A static, responsive portfolio page built with HTML, CSS and JavaScript during my Web Developer internship at Codec Technologies Pvt. Ltd.

## Files
- `index.html`: the page (Home, About, Contact)
- `style.css`: all styles
- `script.js`: mobile menu, typing effect, smooth scrolling
- `profile.png`: profile picture (replace with your own photo, keep the same name)

## Before publishing: edit your social links
In `index.html`, search for these placeholders (they appear twice each: once in the Home section, once in the Contact section) and replace them with your real usernames:

- `your_instagram`  -> `https://instagram.com/<your username>`
- `your_facebook`   -> `https://facebook.com/<your username>`
- `your_twitter`    -> `https://twitter.com/<your username>`
- `your_github`     -> `https://github.com/<your username>`

## Publish on GitHub Pages
1. Create a new repository on GitHub, for example `portfolio`.
2. Upload all the files from this folder (Add file > Upload files), then commit.
3. Open Settings > Pages. Under "Build and deployment" choose "Deploy from a branch", select `main` and `/ (root)`, then Save.
4. After a minute your site is live at `https://<your-username>.github.io/portfolio/`.

(Tip: a repository named exactly `<your-username>.github.io` is served at `https://<your-username>.github.io/`.)

## Run locally
Double-click `index.html`. An internet connection is needed for the Font Awesome icons.
